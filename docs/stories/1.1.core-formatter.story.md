# Story 1.1 — JSONForge Core: Format, Validate, Tree-view & History

**Epic:** 1 — JSONForge MVP
**Autor:** @sm (River)
**Status:** Done
**Estimativa:** M (meio dia)

---

## Story

**As a** desenvolvedor lidando com JSON cru,
**I want** colar JSON e vê-lo formatado, validado e navegável em tree-view, com histórico local,
**so that** eu inspecione e corrija payloads rapidamente sem mandar dados para nenhum servidor.

## Contexto

Implementa o MVP completo do JSONForge conforme PRD v1.0, Architecture v1.0 e UX Spec v1.0.
App single-page, client-side, deploy estático no Vercel. Cobre FR-1 a FR-10 e NFR-1 a NFR-5.

## Acceptance Criteria

- **AC-1** — Dado um JSON válido colado no input, o output exibe o JSON formatado (indent 2 por padrão)
  E uma tree-view colapsável com tipos coloridos. *(FR-1, FR-2, FR-5)*
- **AC-2** — Dado um JSON inválido, um banner de erro exibe a mensagem **com linha e coluna**,
  sem quebrar a UI nem o app. *(FR-3)*
- **AC-3** — O botão **Minify** produz o JSON em uma linha; **Copy** copia o resultado atual
  e mostra confirmação visual. *(FR-4, FR-6)*
- **AC-4** — A barra de estatísticas mostra nº de chaves, profundidade máxima e tamanho em bytes
  para JSON válido. *(FR-7)*
- **AC-5** — As últimas 10 entradas válidas são salvas em `localStorage`; recarregam ao clicar;
  persistem após refresh. *(FR-8)*
- **AC-6** — Botões **Clear** (limpa input) e **Load sample** (carrega JSON de exemplo) funcionam.
  *(FR-9, FR-10)*
- **AC-7** — Toggle entre indentação **2/4 espaços** reflete no output formatado. *(FR-2)*
- **AC-8** — Layout responsivo: duas colunas ≥900px, coluna única <900px; sem overflow horizontal. *(NFR-4)*
- **AC-9** — Nenhuma requisição de rede com conteúdo do usuário; app funciona offline após load. *(NFR-1)*
- **AC-10** — Build `vite build` gera `dist/` estático; testes Vitest da lógica pura passam. *(NFR-5)*

## Dev Notes

- Lógica de domínio em `lib/` é pura — não importa React (testável isolada).
- Error-locator: extrair `position` do `SyntaxError.message`, converter para linha/coluna contando `\n`.
- `localStorage` sempre dentro de try/catch (modo privado / quota).
- Debounce manual com `setTimeout`/`clearTimeout` em `useEffect` (sem lodash).
